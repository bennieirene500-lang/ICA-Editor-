# ICA project state

## Locked

- Member communicates; ICA produces.
- Upload → Produce → Choose outcome → Preview → Download.
- Protect smoothness first; improve production second.
- No timeline and no open-ended editing loop.
- Captions are included by default; a caption-free version is prepared only after preview when requested.
- Every visual must earn its place.
- The speaker remains the hero.

## Current milestone

Milestone 10 converts the approved Milestone 9 product into a controlled Render + Supabase beta foundation.

## Current test group

Founder first, then one trusted member, then five total beta members.

## Current infrastructure

- GitHub: source and deployment history
- Render: frontend, backend and FFmpeg processing in one Docker web service
- Supabase: authentication, member profiles and monthly video allowances
- OpenAI: transcription and Producer Brain analysis
- Render temporary filesystem: short-lived beta outputs only
